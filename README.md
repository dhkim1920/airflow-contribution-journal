# Airflow 기여 기록장

Apache Airflow 기여를 준비하고 기록하기 위한 개인 노트, 계획, 작업 로그 저장소입니다.

## 목적

이 저장소는 Apache Airflow 기여 과정에 대한 **개인 작성 노트**를 모아두기 위한 공간입니다.
Apache Airflow 소스 코드나 문서를 미러링하거나, 포크를 대체하거나, 비공식 재배포를 하기 위한 저장소가 아닙니다.

## 저작권 이슈를 줄이기 위한 원칙

1. 가능한 한 내 말로 요약해서 적습니다.
2. 공식 Airflow 문서는 복사보다 링크를 우선합니다.
3. 짧은 인용이 필요하면 범위를 작게 유지하고, 인용 표시와 출처 URL을 함께 남깁니다.
4. Airflow 문서, 소스 파일, 이미지, 로고를 큰 단위로 복사하지 않습니다.
5. 이 저장소가 Apache Software Foundation의 공식 저장소처럼 보이게 만들지 않습니다.

## 권장 사용 흐름

1. `notes/issues-to-explore.md`에 살펴볼 이슈 후보를 적습니다.
2. `notes/research-log.md`에 조사한 내용과 배운 점을 남깁니다.
3. `notes/work-log.md`에 기여 계획과 실제 작업 기록을 남깁니다.
4. `resources/official-links.md`에는 공식 링크와 짧은 출처 정보만 모아둡니다.
5. 실제 코드 기여는 별도의 Airflow 포크 저장소에서 진행합니다.

## 권장 안내 문구

GitHub 저장소 설명이나 README 상단에는 아래 문구를 사용할 수 있습니다.
